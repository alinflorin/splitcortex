# CLI node (`src/cli-node`)

Rules: [CLAUDE.md](../CLAUDE.md). A **headless Rust node** for Linux, macOS, Windows (the only desktop/server node; no GUI, decided): enroll with a code, connect out, download the pool's model, serve. One binary plus the engine library, installed by a script.

**Ported code**: `crypto.rs`, `handshake.rs`, `connection.rs`, `enroll.rs`, `models.rs`, `runtime.rs`, `engine/compute.rs` port the web node's TS (`enrollment/crypto.ts`, `protocol/handshake.ts`, `protocol/connection.ts`, `enrollment/client.ts`, `models/manager.ts`, `runtime/NodeRuntime.ts`, `engine/compute.ts`). **A fix in one belongs in the other.** Shared contracts: the protobuf (generated by `build.rs` from `src/gateway/proto`), enrollment crypto (`src/control-plane/src/enrollment/crypto.ts`), handshake labels (`src/gateway/src/node_ws.rs`).

## Stack

Rust 2024, tokio, tokio-tungstenite, reqwest (**rustls with OS root certs**, no OpenSSL), prost, curve25519-dalek + sha2 (CPace), ed25519-dalek, hkdf, chacha20poly1305, libloading, clap, sysinfo, keepawake. Scripts: `fetch-litert.py` (pinned LiteRT-LM v0.19.1 zip + SHA-256), `set-version.py`, `package.py`, `install.sh`, `install.ps1`.

## Commands

`splitcortex-node join [--url <web app>] [--code XXXX-XXXXXX]` (address: `--url`, `SPLITCORTEX_URL`, `settings.json` `appUrl`, else `https://splitcortex.com`; `https://host` and `https://host/api` both work), `run` (foreground; waits for approval), `status`, `leave`, `config [--compute auto|cpu|gpu] [--context N] [--keep-awake true|false] [--url ...] [--models-dir /abs/path]`, `update [--check]`, `service install|uninstall|status`. Admin overrides win over `config`, field by field. Platform `cli`. Logs to stderr (`RUST_LOG`), never prompts/completions.

## State and engine

- Data dir (`directories`; `SPLITCORTEX_HOME` overrides): `models/`, `secrets/device-key` (0600, dir 0700; Windows relies on profile ACL), `enrollment.json`, `settings.json`, `backend-bench.json`. Software Ed25519 key.
- **Models dir** is movable: `config --models-dir` (`modelsDir`, empty resets; `SPLITCORTEX_MODELS_DIR` wins). Only models move. Existing files aren't moved (re-download or move `<id>.litertlm` + `<id>.ok`). **One node per models folder**. The node only lists/deletes `<model uuid>.litertlm|.ok` (`storage::is_model_file`), so other files are safe.
- **Engine**: Google's LiteRT-LM C API (`litert_lm_c_api-1.0.0.zip` of v0.19.1) via `libloading`; `ffi.rs` declares only what's used (no bindgen); never unloaded (`ManuallyDrop`). Libraries for linux x86_64/arm64, windows x86_64, macOS arm64, **none for macOS x86_64**. Updating = change `VERSION`/`SHA256` in `fetch-litert.py` and re-check `ffi.rs` against the headers. Library found in `litert/` next to the executable (symlinks resolved) or `SPLITCORTEX_LITERT_LIB`. One generation at a time; `create_best` tries media on then off, each with MTP then without. `gpuAvailable`: macOS, Windows, Linux when `libvulkan.so.1` loads (only gates the automatic CPU-vs-GPU measurement). `Engine::modalities()` feeds `ModelState.modalities`.
- **Embedding models** (`models.rs` `Kind`, `engine/embed.rs`): loaded into LiteRT-LM's embedding engine; loading either kind unloads the other. Dimension from `litert_lm_loaded_file_embedding_dimension`, else probe. READY with `embedding_dimension`, no modalities, context 0. Backend: `gpu` choice else CPU (failed GPU falls back). Per input: trim, EmbeddingGemma prefix by `task` (same strings as the other nodes), **one batch call** (overflow "error"), truncate + L2-renormalise when `0 < dimensions < full`. One `EmbeddingResult` (seq 1, `prompt_tokens` 0) or `InferenceError` (`bad_input`, `engine_error`, `model_not_ready`, `wrong_model_kind`, `restarting`). Embeddings queue (no `busy`). NaN/infinity = `engine_error`.
- **Remote restart** (`restart.rs`, `runtime.rs`): new requests get `restarting`; running ones finish within grace (embeddings +5 s), then models and connection stop and `runtime::run` returns `End::Restart`. `main` relaunches: **Unix `exec`s the same binary/args in place** (same PID for systemd/launchd; after `update` the new file starts); **Windows** spawns a detached process and exits 0. Failed relaunch exits 75. Installed units use `Restart=always` / `KeepAlive`.
- **Fake engine** (`engine/fake.rs`, hidden `run --fake`, env `SPLITCORTEX_FAKE_ENGINE`; `--fake-first-token-ms` 20, `--fake-tokens-per-sec` 200 (0 = no delay), `--fake-dimension` 768): for tests/load. **Everything else is the real node** (enrollment, handshake, assignments, `ModelState`, credits, resume, telemetry). Loads without a file, the model manager **downloads nothing** (`ComputeEngine::is_fake`), `generate` streams `tok0 tok1 …` (`max_tokens` pieces, 32 if unset; cancel ends normally), embeddings are deterministic SHA-256-seeded unit vectors (prefix/truncation/renormalising still run). Text only. Logs a `FAKE ENGINE` warning. **Never in a customer pool**; one node per `SPLITCORTEX_HOME`, so many fake nodes = many processes.
- One request at a time (`busy`); chunks carry `seq` and stay in an outbox 60 s for `Resume`; running requests dropped after 40 s without a gateway.

## Install, service, update

- **Install**: `curl -fsSL https://raw.githubusercontent.com/alinflorin/splitcortex/main/src/cli-node/install.sh | sh` (Linux x64/arm64, macOS arm64), `irm …/install.ps1 | iex` (Windows x64). Finds the newest `cli-node-v*` release via the GitHub API (not `releases/latest`), verifies `.sha256`, unpacks into `~/.local/lib/splitcortex-node` (`%LOCALAPPDATA%\Programs\SplitCortexNode`) with a link in `~/.local/bin` (Windows: user PATH). Tunable: `SPLITCORTEX_VERSION`, `_INSTALL_DIR`, `_BIN_DIR`, `_URL`. Asks for the web app address via `/dev/tty` (skipped without a terminal), saves with `config --url`. `curl`/`irm` downloads carry no quarantine mark, so Gatekeeper/SmartScreen don't block the unsigned binary.
- **Service**: `service install` writes a systemd **user** unit (with `loginctl enable-linger`), a launchd agent, or a logon scheduled task running `splitcortex-node run`.
- **Update**: newest published `cli-node-vX.Y.Z` (no drafts/pre-releases/other streams), verifies checksum, replaces binary and library in place (Windows moves the running `.exe` to `.old`). Restart afterwards.

## Release and CI

- **Tag `cli-node-vX.Y.Z`**: `cli-node-release.yaml` creates the release (not latest) and builds linux x64 (`ubuntu-22.04`), linux arm64, macOS arm64, Windows x64 (`set-version.py`, `fetch-litert.py --required`, `cargo build --release --target`, `package.py`, `gh release upload`). No secrets.
- **CI** `cli-node.yaml` (path filter includes `src/gateway/proto/**`): `cargo test` on all four platforms, `fmt --check` + `clippy -D warnings` on Linux x64, `shellcheck install.sh`. Release profile: thin LTO, 16 codegen units.
