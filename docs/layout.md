# Layout: chart and services

Summary in [CLAUDE.md](../CLAUDE.md).

## Chart (`chart/`)

`Chart.yaml`, `templates/_helpers.tpl`, `values.yaml` (local dev), `values-stg.yaml`, `values-prd.yaml` (layered with `-f`), optional git-ignored `values-local.yaml` (personal overrides). `Chart.lock` committed, `chart/charts/` git-ignored (`helm dependency build chart`). Workloads, services, ingresses and secrets are under per-service values blocks (see Services).

**Dependencies** (each toggled with `<name>.enabled`):
- **Traefik** `traefik/traefik` 42.4.0 (https://traefik.github.io/charts). IngressClass named `traefik` (`traefik.ingressClass.name`), independent of the release name. The `web` entryPoint redirects everything to `websecure` globally (`traefik.ports.web.http.redirections.entryPoint`; 302 dev, 301 stg/prd), so Ingresses need no redirect middleware (HTTP-01 still works).
- **cert-manager** `jetstack/cert-manager` v1.21.3 (https://charts.jetstack.io), CRDs enabled.
- **Dex** `dex/dex` 0.26.0 (https://charts.dexidp.io): `image.tag: latest` with `pullPolicy: Always` (moving tag; pin if reproducibility matters); `enablePasswordDB: true`, `oauth2.skipApprovalScreen: true`, `expiry.idTokens: 15m`, refresh tokens 2160h (`validIfNotUsedFor` and `absoluteLifetime`), `reuseInterval: 30s` (racing renewals from two tabs/reload don't fail with "claimed twice"), Kubernetes storage. Issuer `https://dex.splitcortex.127.0.0.1.nip.io` locally (TLS `root-ca-issuer`, `rate-limit-general`, assumes namespace `splitcortex`); stg/prd use `https://dex.stg.splitcortex.alinflorinciu.qoffice.ro` / `https://dex.prd.splitcortex.com` with `letsencrypt` and enable the Google connector (`${GOOGLE_CLIENT_ID}`/`${GOOGLE_CLIENT_SECRET}` placeholders substituted by `envsubst` at deploy time from GitHub environment secrets, never committed; redirect URIs `https://dex.stg.splitcortex.alinflorinciu.qoffice.ro/callback` and `https://dex.prd.splitcortex.com/callback`; one Google client may serve both, split before prd has real users). Each env registers the public `splitcortex-ui` static client, `allowedOrigins: ["*"]` and an `allowedHeaders` list. The initial local user (bcrypt hash) is only in git-ignored `values-local.yaml`.
- **PostgreSQL** `groundhog2k/postgres` 1.6.8 (https://groundhog2k.github.io/helm-charts/), service `postgres`. `templates/postgres-credentials.yaml` generates random superuser/app passwords once (reused on upgrade via `lookup`) into Secret `postgres-credentials` (kept on uninstall, matching the retained PVC), which also carries a ready `DATABASE_URL`; subchart values only reference its keys.
- **Garage** (object storage, see [control-plane.md](control-plane.md)).
- **ClusterIssuers** (`templates/cluster-issuers.yaml`, Helm post-install/post-upgrade hooks, install with `--wait`, not removed on uninstall): `root-ca-issuer` (CA backed by a self-signed root via `selfsigned-issuer`) everywhere; `letsencrypt` (production ACME, HTTP-01 through Traefik) only when `letsencryptEmail` is set (the only issuer value; in stg/prd the placeholder `"${LETSENCRYPT_EMAIL}"`, substituted by `envsubst '$LETSENCRYPT_EMAIL' < chart/values-<env>.yaml`; the template fails if the placeholder remains; CI validate uses a dummy address). Names/settings hardcoded; don't add issuers to values.

**Constraints**:
- Postgres is external; the gateway needs a direct connection (uses `LISTEN`), not PgBouncer transaction mode.
- Gateway default 1 replica; more replicas forward internally (see [gateway.md](gateway.md)). SSE and wss must not be cut by Traefik's entryPoint `respondingTimeouts` (static Traefik config).
- Gateway private key comes from a Secret mounted as a file (see gateway.md); only the public key and wss URL go to the control plane. Prefer `existingSecret` outside dev; no inline secrets in stg/prd.
- External ingress controller: `traefik.enabled=false`, set `ingress.className` (also used by the ACME solver) and `dex.ingress.className`, `rateLimit.enabled=false` unless it's Traefik with CRDs, replace `traefik.ingress.kubernetes.io/*` annotations, configure the HTTP→HTTPS redirect there. External cert-manager: `cert-manager.enabled=false` (CRDs and webhook must exist; our issuer names must not clash); to use its issuers set `clusterIssuers.enabled=false` and point the Ingress `cert-manager.io/cluster-issuer` annotation at them.
- Rate limits (`templates/rate-limits.yaml`, values under `rateLimit`): Middlewares `rate-limit-general` (per client IP, 50/s burst 100; web app, control plane, Dex) and `rate-limit-gateway` (per `Authorization` header, 2000/s burst 4000, coarse flood ceiling only; the gateway enforces real per-key limits). **Not on the entryPoint** (would throttle the gateway): attach per route via `router.middlewares`/IngressRoute.
- Dev only, `dev.coredns.enabled` (on in `values.yaml`, off in stg/prd): `templates/coredns-custom.yaml` creates the k3s `coredns-custom` ConfigMap in `kube-system` with `rewrite name exact <host> traefik.<ns>.svc.cluster.local` for each host in `dev.coredns.hosts` (currently the Dex host), so pods resolve nip.io names to Traefik. It replaces any existing `coredns-custom`; add new dev hostnames to the list.
- No Redis, no serverless. Enrollment goes through the control plane ingress, never the gateway.

## Services

- `src/ui/`: web app, see [ui.md](ui.md). `Dockerfile` + `Dockerfile.dev`, chart `ui-*.yaml` under `ui:` (ingress at the web app host).
- `src/web-node/`: [web-node.md](web-node.md). Containerised like the UI (`Dockerfile.dev` Vite HMR on 8080; production: tests, build, Caddy on 8080 with SPA fallback, `/healthz`, non-root; the WASM runtime under `/litertlm/` is revalidated, never cached blindly). Chart `web-node-*.yaml` under `webNode:` (ingress at `web-node.<domain>`, stg/prd override image and host). The control plane's Ingress also lists the web node host (`/api` only; TLS Secret `web-node-tls`, issued through the web node's Ingress).
- `src/control-plane/`: Fastify API (`src/app.ts` builds the app from injected `db` and token verifier so tests need no infrastructure; `routes/`, `plugins/auth.ts`, `dto/`, `db/` with `schema.ts`, `migrate.ts`, `config-changes.ts`; `drizzle/`). `Dockerfile` (prod: runs tests, prod-only deps, non-root), `Dockerfile.dev` (`tsx watch` on 8080). Chart `control-plane-{deployment,service,ingress,migrate-job}.yaml` under `controlPlane:`.
- `src/gateway/`: [gateway.md](gateway.md); chart `gateway-*` under `gateway:`.
- `src/mobile-node/`, `src/desktop-node/`, `src/cli-node/`: device apps, **not deployed by the chart** (no Dockerfile, chart templates or Tiltfile entry); built by `.github/workflows/<name>*.yaml` (see [commands-and-ci.md](commands-and-ci.md)). The CLI node is a Rust binary installed by `install.sh`/`install.ps1`, separate from the desktop node.
- `scripts/start-emulator.sh [avd]`: boots an Android emulator with `-dns-server 127.0.0.1` and starts `dnsmasq` with `sudo` on 127.0.0.1:53 (answers `*.splitcortex.127.0.0.1.nip.io` with `10.0.2.2`, forwards the rest to 1.1.1.1; must be installed), so local nip.io names reach Traefik with the right hostname. It does not touch the CA (install by hand once). Debug builds trust user CAs via `src/mobile-node/plugins/withDevUserCa.js` (debug source set only).
