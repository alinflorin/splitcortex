# Web app (`src/ui`)

Rules: [CLAUDE.md](../CLAUDE.md).

## Stack and conventions

- Vite, React (compiler via experimental Rust port: `react({ compiler: true })` + `oxc-transform-react`), strict TS, Fluent UI only, react-hook-form (`mode: 'onTouched'`) + zod (messages are i18n keys), React Router, TanStack Query.
- **i18n**: language order URL prefix (`/ro/...`) > localStorage `sc-lang` > browser > en; JSON in `public/locales/<lng>/translation.json`. **Theme**: Fluent teams light/dark, System/Light/Dark, persisted; pickers in the avatar menu (also signed out).
- **No CDNs**: Inter self-hosted (`@fontsource-variable/inter`). Only exception: Google Analytics (below).
- **Tests**: Vitest (jsdom, `src/test/setup.ts` stubs `matchMedia`/`ResizeObserver`), RTL next to code; use `renderApp` (`src/test/render.tsx`); mock `react-oidc-context` with `vi.mock`; the chart package is mocked.
- **Design**: light, airy, hairline borders, no heavy shadows, no gradients in chrome. **Brand colours come only from the logo** (success = mint, in-progress = violet; violet `#6C7BF2`→`#4A5BE6`, mint `#2CE6C5`→cyan `#14B8D4`) via `src/theme/brand.ts` (`BRAND` + Fluent brand tokens from `#4A5BE6` over the Teams themes); never write brand hex elsewhere. `web-node`, `mobile-node` and the Dex theme (`chart/files/dex-theme/styles.css`) hold hand copies.
- **Layout**: every page uses `PageHeader`. `AppShell`: top bar on every page (logo = Home, Home, Organisations, Playground, About, Contact, avatar menu), a **breadcrumb** on organisation pages (replaces any "back" link), the page. The **sidebar exists only inside an organisation** (`/organisations/:orgId/*`): 232 px, flat, collapses to a 56 px rail (`localStorage` `sc-sidebar-collapsed`). Below 1024 px top links + sidebar become one drawer. Pages use a 1280 px column (Home is full width and lays out its own column); forms 640 px. Below 600 px / coarse pointers, buttons and nav items are ≥44 px. Empty lists use `EmptyState`. Route fade-in `.sc-enter` (off under `prefers-reduced-motion`).

## Auth

**Dex OIDC** via `react-oidc-context` (public client `splitcortex-ui`, code + PKCE). Dex URL from `window.location` (`<domain>` → `https://dex.<domain>`; `VITE_OIDC_AUTHORITY` overrides). No end-session endpoint: sign-out clears the local session. Dex CORS is open (`web.allowedOrigins: ["*"]` + `allowedHeaders`). Tokens last 15 min and `automaticSilentRenew` only runs while the page is awake, so `PrivateRoute` tries `signinSilent()` before sending an expired session to Dex, `SignInOnRenewFailure` signs in again after a failed renewal, and every call takes its token from `auth/useFreshToken.ts` (renews under 30 s, one shared renewal; `useRequest` replays once after a 401). Home, Quick start, Help, About, Terms, Privacy, Contact are public (en + ro, see SEO); everything else is behind `PrivateRoute`.

## Data and feedback

- Control plane calls via TanStack Query (`src/api/`: `client.ts` fetch + zod parsing, same-origin `/api` or `VITE_API_URL`; `hooks.ts`; `ApiProvider` toasts failed mutations; `schemas.ts` hand-synced DTOs). Queries wait for the token. Role gating (`lib/roles.ts`) mirrors the server and is only convenience.
- Use `useConfirm()` and `useToast()` (`components/feedback/`), not ad-hoc dialogs.

## Pages

- **Cards, never tables** (`components/cards`: `CardList`, `ItemCard`, `Stat`/`StatRow`; one column on mobile, `variant="grid"` from 720 px).
- Org sidebar (`OrgNav.tsx`): Models, Pools, API keys, Members, Usage, Metrics, Audit log, Settings (API keys, Audit, Settings admin-only). Private routes: `/organisations`, `/organisations/:orgId/{pools, pools/:poolId, models, api-keys, members, usage, metrics, audit, settings}`, `.../nodes/:nodeId`, `/playground`, `/user-settings`.
- **Pool screen**: admin buttons **Add web node** (creates a code, opens `https://web-node.<domain>/#code=...`; `VITE_WEB_NODE_URL` overrides), **Add many devices** (`BulkEnrollDialog`, 1..50, CSV, cancels unused on close), **Add device** (`EnrollDeviceDialog`: code + QR with countdown, closes when a node appears); **Benchmarks** poll every 3 s while running. Pools list refreshes every 10 s.
- **Node page**: status, telemetry, approve/revoke, admin **Restart** (disabled unless online), engine overrides (context 512–131072, saved on change/blur); polls every 10 s.
- **API keys**: **Expiring soon** under 7 days; create (org or pool scope, expiry, limits); one-time secret dialog with **Use this key** examples (gateway `gateway.<domain>/v1`, `VITE_GATEWAY_URL` overrides, `lib/gateway.ts`).
- **Models**: add from Hugging Face link or upload with part-level retry (`lib/uploadParts.ts`); **Type** Chat/Embeddings (embeddings are left out of the Playground picker).
- **Account settings**: danger zone `DELETE /api/me` (toast names orgs where the user is sole owner).
- **Audit log** (admin/owner, others redirected): labels `audit.actions.<action>` (new actions need en + ro), filters, **Load more**, CSV/JSON export.
- **Limits**: `LimitsFields` (empty = unlimited) in org settings, key creation, key dialog.
- **Playground**: user **pastes an API key** (component state only); `GET /v1/models` fills the picker; `POST /v1/chat/completions` streams SSE (`lib/chatStream.ts`; stop aborts so the gateway cancels the node). **Attachments** (`lib/attachments.ts`; paperclip/drop/paste, microphone via `MediaRecorder`): images the gateway accepts (JPEG/PNG/GIF/BMP ≤1 MiB) as is, others scaled to 1024 px JPEG; audio wav/mp3/flac ≤5 MiB as is, else decoded to 16 kHz mono WAV (≤10 min); text files ≤200 KiB become a fenced `[File: name]` block; PDFs/binaries refused. Warns when the model's `input_modalities` lacks an attached kind. **No chat memory** (conversation resent each turn). Markdown via `react-markdown` (no raw HTML). Calls go to **`/v1` on the app's origin** (`getPlaygroundBaseUrl`), routed by `gateway.appIngress`: **no CORS on the gateway**.
- **Home**: animated `NetworkDiagram`, a **scroll tour** (`components/marketing/ScrollTour.tsx` + `tourScene.ts`: Three.js, 4 chapters from `home.tour`, 480vh block with sticky stage; lazy-loaded, follows the theme via `TourScene.setTheme`, static under `prefers-reduced-motion`, hidden without WebGL), steps, feature cards, curl example, **Run a node** (`AppDownloads bare`), **Endpoints**, call to action. **About** links to `/terms`, `/privacy` (`pages/Legal.tsx`, copy `legal.*`) and `/contact` (placeholder details in `contact.*`). Public copy keeps internal plans, pricing and tech stack out (WebGPU and LiteRT-LM named on purpose). Copy in `home.*`/`about.*`.
- **Quick start** (`pages/QuickStart.tsx`, copy `quickstart.*`, public, en + ro, `/quick-start`): the six first-run steps (organisation, model, pool, devices, key, call) with the node downloads, endpoints and curl/Python examples, then the three fields any OpenAI-compatible tool needs, example software (Cherry Studio, Jan, Open WebUI, Continue, n8n, SDKs…, names only, no affiliation implied), and a section on agents. **Keep it true to the gateway**: no native tool calling (agents must read text answers), no CORS (browser pages need their own backend), key prefix `sc_`. Help links to it; the steps live only here.
- **Help** (`pages/Help.tsx`, copy `help.*`, public, en + ro): end-user guide in anchored sections (`#devices`, `#models`, `#api`, `#access`, `#monitor`, `#troubleshoot`) reusing `AppDownloads`, `Endpoints` and `CodeBlock`; linked from the top bar and footer. Keep it to what users see and do (no internal plans, pricing or stack beyond WebGPU/LiteRT-LM) and in step with the product: when a user-visible behaviour changes (limits, errors, enrollment, roles), update `help.*` in both languages. A unit test checks that `ro` has the same shape as `en`.
- **`AppDownloads`** (`#run`): Mobile app (APK → release `mobile-node-latest`), Command line (`install.sh`/`install.ps1` from GitHub raw, release `cli-node-latest`), Web node (open/share). Each stream has a rolling `<stream>-latest` release from `rolling-release.yaml`.
- **Version**: account menu and org sidebar footer show the chart version from `/version.json` (Caddy serves `APP_VERSION`; Vite dev has the same route).

## Charts

`@fluentui/react-charts` via `components/charts/TimeCharts.tsx`. `MetricsView`: **live** (15 s refresh, a switch freezes, 15 min–7 days) at org, pool and node level; device charts show **measured tokens/s** and **failure rate** beside reported tokens/s. `UsageView` has request/token charts above period cards.

## SEO

Goal: the seven public pages are found in en **and** ro; the signed-in app and every non-public host never are. One image runs everywhere, so nothing environment-specific is baked in.

- **URLs**: English bare (`/about`), Romanian under `/ro`. `seo/pages.ts` (`PUBLIC_PAGES`, `localizedPath`, `parsePublicPath`) is the single list for sitemap, hreflang, canonicals, prerender, footer. `App.tsx` mounts public routes once per language. Links to public pages use `useLocalePath()`.
- **Language and URL stay in step** (`seo/LocaleSync.tsx`): switching language goes to the same page in the other language; a bare public URL opened by a Romanian-preferring user redirects to `/ro/...` (replace); sign-in returns (`/?code=...&state=...`) are left alone; `returnToOf` sends a user without target to their language's home. Crawlers see each URL as written. The signed-in app has no language in its URL.
- **Head** (`seo/head.ts`, `seo/Seo.tsx`): pure `buildHead` makes title, description, robots, canonical, hreflang (`en`, `ro`, `x-default` = en), Open Graph, Twitter, JSON-LD (Organization + WebSite on Home, BreadcrumbList elsewhere); used by the prerender and (`applyHead`) on every navigation. Texts `seo.*` in both locales (title ≤65, description ≤170; a unit test checks). Any other path gets `noindex, nofollow`.
- **Prerender** (`pnpm build` = `tsc -b && vite build && vite build --ssr src/entry-server.tsx --outDir dist-ssr && node scripts/prerender.mjs`): `entry-server.tsx` renders the real app (Fluent `RendererProvider`/`SSRProvider`, stub signed-out `AuthContext`, `StaticRouter`, per-language i18n) via `renderToString`; the script writes `dist/<path>/index.html` per public URL, `dist/app.html` (content-less `noindex` shell for everything else) and `dist/sitemap.xml`. **No hydration**: `main.tsx` waits for `i18nReady`, then `createRoot` replaces the HTML. Pages must render without a browser: no `window`/`document` at render time except what the script stubs (`location`, `localStorage`, `matchMedia`); `useSyncExternalStore` needs a server snapshot. Build fails if a page renders no `<h1>`. An inline script in `index.html` paints dark background for dark-theme users until the app takes over.
- **Host at runtime**: canonical/hreflang/OG URLs, sitemap and Home's endpoints carry `{{.Host}}`, filled by Caddy `templates` per request (any other `{{` is escaped). Hence **no `.br` copies of `.html`/`.xml`**.
- **Caddy**: `/robots.txt` and `/sitemap.xml` by environment; `@app` routes (`/organisations*`, `/playground`, `/user-settings`) serve `app.html` with `X-Robots-Tag: noindex`; else files (`file_server { disable_canonical_uris }`: no trailing-slash redirect); non-files are a real **404** with the shell; hashed `/assets/*` immutable, rest `no-cache`.
- **Indexable only in prod**: `SEO_INDEXABLE=true` (`ui.seo.indexable`, `values-prd.yaml`). Elsewhere: `X-Robots-Tag: noindex, nofollow, noarchive`, `robots.txt` = `Disallow: /`, `sitemap.xml` 404. In prod `robots.txt` allows all except `/api/` and `/v1/` and lists the sitemap; signed-in pages are deliberately **not** disallowed (crawlers must read their `noindex`). Other hosts get it from the Traefik `noindex` middleware; the web node's Caddy also serves `Disallow: /`.
- **Footer** (`SiteFooter.tsx`, public pages only): links to every public page (Google's OAuth consent review wants the legal pages reachable from home) and `hreflang` links to the other language.
- **Assets** in `public/`: `og-image.png` (1200x630, source `scripts/brand/og-image.html`, rendered with Chromium), `logo-192/512.png`, `apple-touch-icon.png`, `favicon.ico` (`rsvg-convert` + `magick`), `site.webmanifest`. Regenerate when the logo changes; brand hex in them and `index.html` `theme-color` are hand copies of `theme/brand.ts`.
- **Adding a public page**: `PUBLIC_PAGES`, a route in `publicRoutes()` (`App.tsx`), `seo.<key>.title|description` in en + ro, a footer label; sitemap, hreflang, prerender and e2e (`seo.spec.ts`) follow.

## Analytics

Google Analytics 4 (`gtag.js`, **the only third party the browser talks to**). One stream per app: web app `G-KYDDYPE4NM`, web node `G-DY77W04DVM` (public ids in `values-prd.yaml`).

- **Prod only**: id from chart (`ui.analytics.measurementId`, `webNode.analytics.measurementId`; empty elsewhere) via env `GA_MEASUREMENT_ID`, served by Caddy at `/config.json` (`{"analyticsId": ""}` elsewhere). No id = no banner, no script, no request to Google.
- **Consent first** (`analytics/consent.ts`, `ConsentBanner.tsx`): banner (en + ro, `consent.*`), Accept and Decline look alike, link to privacy; choice in `localStorage` `sc-consent`; "Cookie settings" in the account menu (only where an id is set). `gtag.js` is injected only on `granted`. Consent Mode v2 defaults all `denied`; Google signals and ad personalization off. Declining/withdrawing sets `ga-disable-<id>`, revokes consent, deletes `_ga*` cookies.
- **Sent** (`analytics/gtag.ts`): page views only (`Analytics.tsx`). Paths have org/pool/device ids (and any uuid/long hex) replaced by `:id`; no query, no hash; generic title. Never typed text, prompts, answers, keys or codes. Privacy policy (`legal.privacy`) and terms (`legal.terms`) say so in en + ro (consent-based, Google as processor, no advertising use, possible non-EEA processing, limited retention, withdrawal): keep them in step.
- The web node has its own copy of `analytics/` (no shared code; keep in step); its banner links to `<domain>/privacy`.
- **Tests**: Vitest `analytics/*.test.ts(x)` in both projects; e2e `analytics.spec.ts` (Google blocked).
